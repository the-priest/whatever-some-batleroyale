BLOCK ROYALE
============

WINDOWS:  double-click BlockRoyale.exe
LINUX:    double-click BlockRoyale.x86_64, or in a terminal:
              chmod +x BlockRoyale.x86_64
              ./BlockRoyale.x86_64

The game starts fullscreen. F11 or Alt + Enter switches to a window.
Settings (main menu or Esc in a match): graphics preset, upscaling (FSR 2),
vsync, FPS counter, mouse sensitivity, field of view, volume, music.

PLAYING TOGETHER
- One player presses HOST GAME. Friends press JOIN GAME: games on the same
  network show up in the list; for a game over the internet, type the host's
  address (and the password, if the host set one).
- The host can press OPEN TO THE INTERNET in the lobby (asks the router to
  open UDP port 24555), set a PASSWORD, and KICK players (Shift + click bans).
- If Windows asks whether to let the game through the firewall, allow it.

CONTROLS
WASD move · Shift sprint · C / Ctrl crouch · Space jump, vault, parachute
Left mouse fire · Right mouse aim · R reload · B fire mode · Q / E lean
F pick up, get in or out of a jeep · 1 / 2 / wheel switch weapon
H heal · 4 / 5 / 6 bandage, medkit, energy drink · G grenade
M map (click to mark, wheel to zoom) · Tab scoreboard · Enter chat · Esc pause
